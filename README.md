# Amazon Prime Movies and TV Shows – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Amazon Prime Movies and TV Shows data.

The main objective is to explore the dataset, identify patterns and trends, understand content distribution, and discover meaningful business insights through data analysis and visualization.

## Datasets Used

This project uses two datasets:

- **Titles Dataset:** Contains information about movies and TV shows, including title, type, release year, genres, runtime, IMDb ratings, and TMDB scores.
- **Credits Dataset:** Contains information about actors, directors, characters, and their roles.

Both datasets were combined using their common `id` column.
