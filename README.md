# Amazon Prime Movies and TV Shows – EDA

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of Amazon Prime Movies and TV Shows data.

The aim is to understand the dataset, identify patterns, and present useful insights through data visualization.

## Datasets Used
- **Titles Dataset:** Contains information about movies and TV shows.
- **Credits Dataset:** Contains information about actors, directors, and their roles.

The two datasets were combined using their common ID column.

## Tools and Technologies
- Python
- Google Collab
- Pandas
- Matplotlib
- Seaborn

## Project Steps
1. Load the datasets.
2. Explore the dataset structure.
3. Check missing values and duplicates.
4. Clean and merge the datasets.
5. Perform Exploratory Data Analysis.
6. Create graphs and visualizations.
7. Prepare an Insights PDF report.

## Visualizations
The project explores:
- Movies vs TV Shows
- Top Genres
- Production Countries
- Runtime Distribution
- IMDb Ratings
- Top Directors

## Project Files
- `Amazon_Prime_EDA.ipynb` – Completed EDA notebook.
- `Amazon_Prime_Insights_Report.pdf` – Insights report.
- `Graphs/` – Graph images.

## Conclusion
This project uses data analysis and visualization to understand the characteristics and patterns in the Amazon Prime Movies and TV Shows dataset.
